In order to use SOTA embeddings and create embeddings in our local machine we can need to install instructorEmbeddings

pip install instructorEmbedding
pip install sentence_transformers      -> this is basically dependency of instructorEmbedding. So we have to install both of them together. 


make sure to always install all the packages and correct version of langchain, otherwise the deployment
will always fail.

python -m streamlit run app.py --server.port 8000 --server.address 0.0.0.0
